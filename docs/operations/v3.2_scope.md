# v3.2 Scope — Healthcare Early Read

**Status:** In development (scope locked, not yet shipped)
**Target:** Add the first non-current sector to the Deflation Index, framed as an "early read" matching the v3.1 pattern.
**Anchor data:** NHGRI cost-per-genome series.

---

## One-line goal

Publish a measured healthcare input-layer line on the site — the NHGRI genomic sequencing cost curve, 2001–present — as the first concrete step from "we plan to expand" to "we have expanded."

## Why this release

The v3.1.2 site rewrite committed the project to the input-layer principle: the Deflation Index measures technology-driven input cost reductions across all sectors, including those whose headline consumer prices haven't responded. Healthcare is the most important test of that principle, because the gap between input layer (genomic sequencing, AI radiology, telemedicine) and headline layer (insurance premiums, hospital bills) is the largest in the economy.

NHGRI publishes the cost-per-genome series annually at <https://www.genome.gov/about-genomics/fact-sheets/Sequencing-Human-Genome-cost>. It is a Tier-1 source by every standard the project applies to the existing four sectors: government agency, transparent methodology, twenty-plus-year time series, fully open data. There is no data-availability barrier to publishing it. What's missing is the work.

Shipping v3.2 closes the gap between what the site says ("healthcare will follow") and what the site shows.

## What ships in v3.2

## Out of scope for v3.2

- A full weighted healthcare sector index. That requires composing 3–5 input measurements with explicit weights, which is the v3.3+ scope.
- Education and housing input-layer measurements. Those are separate releases.
- Any change to the four current sectors' weights, methodology, or 1990–2024 series.
- Any new data point for the existing 2025 early-read block.

## Open questions to decide at session start

1. **Single input or composite for v3.2?** Genomic sequencing alone is the cleanest, defensible release. Adding 1–2 more inputs (medical imaging cost-per-scan from CMS Hospital Charge Data; AI-radiology cost from Epoch's compute curves) makes it more representative but adds methodology complexity. Default: ship single-input, leave composite for v3.3.
2. **Rebasing.** NHGRI's series starts in 2001, not 1990. Options: (a) rebase to 2001 = 100 and footnote the anchor difference; (b) project a 1990 baseline using pre-2001 sequencing technology costs; (c) publish raw cost-per-genome on a log scale without rebasing. Default: (c) for the early read, since it's a single line and log-scale dollar values are the most honest presentation.
3. **Home page surface area.** Does the healthcare early-read deserve a callout on the home page, or stay tucked into the Method page? Default: Method-only for v3.2; revisit when the composite ships.
4. **Story essay.** Write the fifth story (`sequencing-the-curve.md`) in the same session, or as a v3.2.1 follow-up? Default: include it — the essay-led explanation is part of how the project communicates new sectors.
